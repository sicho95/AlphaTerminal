Le centre de notifications interne fonctionne indépendamment. Sur iPhone, installe la PWA à l'écran d'accueil et active les notifications ici.

Les notifications système sont facultatives. Si le suivi NAS est actif et qu'elles sont autorisées sur cet appareil, l'abonnement Web Push est automatique ; le NAS continue même quand la PWA est fermée.

La clé cryptographique non exportable reste dans IndexedDB. Le mot de passe n'est pas stocké par AlphaTerminal ; vous pouvez l'enregistrer dans votre trousseau ou gestionnaire de mots de passe.

La comparaison avec le NAS est automatique : en cas de NAS plus récent, AlphaTerminal vous demande quelle version garder. Les clés créées séparément sur deux appareils n'ont pas nécessairement le même sel, même avec le même mot de passe.
